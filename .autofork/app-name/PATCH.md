The app calls itself "T3 Code (Bassim's autofork)": in the macOS menu bar, the
app bundle's name, the About panel, the app menu, the installer and the window
title. Upstream puts its release channel there (Alpha, Nightly, Latest, or
whatever channel comes next), but this build is none of those: it's Bassim's
autofork of T3 Code, so the channel never shows and "T3 Code" stays.

Development runs still say "(Dev)", so a dev build stays easy to tell apart.
Labels that describe the server you're connected to, like the Nightly sidebar
art and pill when the server runs a nightly, stay as upstream made them: they
say what the server is, not what this app is.
